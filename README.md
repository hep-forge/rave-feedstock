Feedstock for [rave](https://rave.hepforge.org) — part of [hep-forge](https://anaconda.org/hep-forge).
Builds linux-amd64 + linux-arm64 in one matrix workflow and uploads to the
[hep-forge](https://anaconda.org/hep-forge) Anaconda channel.

Vertex finding and fitting from reconstructed tracks

## Architectures

State per architecture: see the platforms badge above or [anaconda.org/hep-forge/rave](https://anaconda.org/hep-forge/rave).


## Install

```bash
conda install -c hep-forge -c conda-forge rave
```
